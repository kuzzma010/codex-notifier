# Codex Notifier

**Быстрые ответы:** режим «Отправлять сразу» использует `codex queue` и отправляет сообщение в фоне, не открывая окно и не меняя черновик. Требуется версия Codex CLI с командой `queue`. При ошибке окно не открывается, автоматического повтора нет. Режим вставки для проверки по-прежнему открывает редактор. Чтобы открывать чат только кнопкой, выключите «Открывать чат автоматически».

Запуск: откройте **CodexNotifier.exe**. При первом запуске открываются настройки. Выберите параметры и нажмите **«Сохранить и начать»**. Это переносимый EXE без отдельного установщика.

Программа работает в фоне; значок находится в трее Windows (возможно, под стрелкой рядом с часами). Чтобы вернуться к настройкам: двойной клик по значку или правый клик → **«Настройки…»**.

По умолчанию после завершения ответа: звук → маленькое уведомление → через 30 секунд открывается Codex.

В настройках доступны:

- **Маленькая** — только «Открыть» и три точки. Три точки разворачивают большую карточку, не сбрасывая отсчёт.
- **Большая** — название задачи, отсчёт, кнопки открытия и подтверждения.
- **Тема** — как на устройстве / светлая / тёмная. Автоматический режим использует тему приложений Windows и реагирует на её изменения без перезапуска.
- Звуковой сигнал, автоматическое открытие и задержка 15, 30 или 60 секунд.
- Запуск вместе с Windows.
- Живое превью и тестовое уведомление. Тест из настроек не открывает настоящий чат.
- **Быстрые ответы** — «Да», «Дальше», «Делай» в большой карточке. Режим по умолчанию: вставлять в поле ввода нужной задачи для проверки. Можно выбрать «Отправлять сразу».

В режиме вставки открывается редактор нужной задачи. В режиме отправки сообщение ставится в очередь этой задачи через Codex CLI без показа окна и изменения черновика. Успех команды означает принятие сообщения в очередь, а не завершение ответа. При неподтверждённой отправке автоматического повтора нет.

Карточки имеют скругления и полупрозрачный фон. Фон рабочего стола просвечивает без нативного Acrylic-размытия.

- **Открыть чат** — сразу перейти к задаче и убрать уведомление.
- **Увидел** или крестик — убрать уведомление и отменить автоматическое открытие.
- Новый запрос в той же задаче также убирает её ожидающее уведомление.
- Правый клик по значку: настройки, тест, пауза, выход. Тест из трея открывает окно Codex, если автоматическое открытие включено.
- Автозапуск изначально выключен. При включённом автозапуске не перемещайте EXE; перед перемещением выключите автозапуск, затем включите из нового расположения.
- Повторный запуск не создаёт второй экземпляр.

Программа читает новые события локальных задач из `%USERPROFILE%\.codex\sessions`. Старые завершения при запуске не показываются. Имена задач берёт из локального индекса. Сообщение отправляется только после нажатия пользователем кнопки быстрого ответа в режиме «Отправлять сразу». Несколько завершений показываются по очереди; задержка отсчитывается с показа каждого уведомления.

Ограничения: облачные чаты и запросы подтверждения посреди выполнения пока не отслеживаются. Срабатывает на каждое завершение ответа, а не только на ответы с вопросом. Формат локальных журналов и ссылки приложения могут измениться после обновления Codex. Windows может ограничить перевод фокуса; уведомление остаётся доступным. Звук зависит от системной громкости.

Исходники и интерфейс: файлы `.cs` и `.xaml` в этой папке. Собрать можно через `build.ps1`. Нужен встроенный в Windows .NET Framework 4.x с WPF.
Настройки сохраняются в `%LOCALAPPDATA%\CodexNotifier\settings.json`.
Диагностический журнал без текста переписки: `%LOCALAPPDATA%\CodexNotifier\events.log`.

## Расход ресурсов

Изменения журналов отслеживаются через уведомления файловой системы Windows. Все журналы просматриваются один раз при старте и повторно только при восстановлении после переполнения очереди системных событий. В обычном режиме читаются только изменённые файлы и только новые строки. Тексты ответов и результаты инструментов не разбираются как JSON. История защиты от повторных событий ограничена 2048 записями.

В фоне таймер срабатывает раз в 2 секунды; чаще — только при открытом уведомлении или отправке быстрого ответа. Видимый отсчёт обновляется раз в секунду. Небольшие статичные окна рисуются программно, чтобы не загружать большой стек графического драйвера. Принудительное обрезание рабочего набора памяти не используется.

На этом компьютере в коротких 10-секундных замерах: около 39 МБ рабочего набора после запуска в фоне; около 100 МБ после тестов настроек, карточек и сохранения изображений интерфейса. Во время ожидания — около 0,16% одного логического ядра. Это наблюдения, а не гарантированный предел: расход зависит от открытых окон, DPI и активности задач.

Удаление: выберите «Выход», выключите автозапуск, если включали, и удалите папку. Если уже вышли, запустите EXE снова, чтобы выключить автозапуск.

Проверка после изменений: запустите verify.ps1. Последний аудит: 24 проверки логики и 28 проверок интерфейса. Автоотправка подтверждена двумя реальными отправлениями до дополнительных исправлений аудита. Перед вставкой проверяется сохранённый черновик; несохранённый текст требует отдельной проверки поведения ссылок Codex.
