# Codex Notifier для macOS

Нативная версия для **macOS 13+**, Apple Silicon и Intel. Это исходники и сценарий сборки, **не готовый проверенный .app**: пакет подготовлен на Windows, где нет macOS SDK. Компиляцию, встроенные тесты и проверку работы нужно выполнить на Mac.

## Сборка с установленным Xcode

1. Распакуй архив на Mac.
2. Открой Terminal. Напиши `bash`, поставь пробел и перетащи файл **Build.command** в окно Terminal. Нажми Enter. Либо запусти Build.command двойным кликом, если Finder разрешает его запуск.
3. Сценарий соберёт обе архитектуры, создаст **build/Codex Notifier.app**, проверит локальную подпись и выполнит 13 проверок логики. При ошибке он остановится, не объявляя сборку успешной.
4. Перетащи полученный **Codex Notifier.app** в **Applications** и открой. При первом запуске появятся настройки.

Дополнительные пакеты, Homebrew и платные учётные записи для локальной сборки не нужны. Если `xcrun` не находит компилятор, открой Xcode → Settings → Locations → Command Line Tools и выбери установленный Xcode. Сценарий не меняет выбор Xcode и настройки безопасности самостоятельно.

## Что реализовано в исходниках

- Значок в строке меню: настройки, тест уведомления, переподключение, пауза, выход.
- Маленькая карточка: **Открыть** и **⋯**. Три точки разворачивают большую карточку без сброса отсчёта.
- Большая карточка: название задачи, отсчёт, открытие, «Увидел», быстрые ответы **Да / Дальше / Делай**.
- Системное стекло через NSVisualEffectView. Автоматическая тема macOS и ручной выбор светлой/тёмной.
- Звук, автоматическое открытие через 15/30/60 секунд, запуск при входе в систему.
- Быстрые ответы: вставлять для проверки (по умолчанию) либо отправлять сразу.
- Никакого отдельного AI/API-ключа: утилита взаимодействует с установленным Codex.

## Разрешения и быстрые ответы

Обычные уведомления и вставка ответа не требуют управления клавиатурой. Для режима «Отправлять сразу» macOS требует разрешить приложению **Универсальный доступ / Accessibility**. Кнопка запроса находится в настройках утилиты. Разрешение выдаётся пользователем в системных настройках; без него текст остаётся для ручной отправки. Запись экрана не используется.

Перед отправкой проверяются ID задачи, пустота существующего черновика, совпадение вставленного текста, активное приложение и доступное поле ввода. При ошибке отправка не повторяется автоматически. Доступность этих проверок зависит от версии Codex; автоотправку обязательно проверь на безобидной тестовой задаче. Никогда не используйте тестовое «Да» в задаче, где ожидается нежелательное для вас действие.

Ссылки `codex://threads/<id>?prompt=...` и локальный формат черновиков проверены в установленной Windows-версии Codex; совместимость с вашей Mac-версией ещё не проверена. При несовпадении интерфейса текст можно отправить вручную.

Автозапуск использует системный SMAppService. Если macOS требует одобрения, проверь System Settings → General → Login Items. Перемещать .app лучше до включения автозапуска. Для распространения другим людям потребуется отдельно подписать приложение Developer ID и пройти notarization; включённая ad-hoc подпись предназначена для локальной сборки.

## Нагрузка

Нативные AppKit/SwiftUI, без Electron и браузерного движка. Журналы отслеживаются через FSEvents; периодического обхода всех файлов нет. В покое нет таймера уведомлений. Отсчёт обновляется один раз в секунду и прекращается после закрытия карточки. Проверка быстрого ответа работает максимум 10 секунд, только после нажатия кнопки. История дубликатов ограничена 2048 событиями, очередь уведомлений — 200 задачами, размер обрабатываемой строки — 1 МБ.

**Замеров RAM/CPU на Mac пока нет.** Windows-замеры к этой версии не относятся. После сборки проверь Activity Monitor в покое и после нескольких открытий настроек/уведомлений.

## Локальные данные

- Читаемые журналы: `~/.codex/sessions/`.
- Названия: `~/.codex/session_index.jsonl`.
- Черновики: `~/.codex/.codex-global-state.json`, только для быстрых ответов.
- Настройки утилиты: `~/Library/Application Support/CodexNotifier/settings.json`.

Отслеживаются локальные задачи Codex. Облачные чаты и подтверждения посреди выполнения пока не поддерживаются. Смена полноэкранного режима не вызывается: приложение открывает задачу через системную ссылку.

## Проверка на Mac

1. Собери приложение: должны пройти компиляция обеих архитектур и все 13 core checks.
2. Запусти, выбери настройки и проверь сохранение после перезапуска.
3. Проверь светлую/тёмную тему, маленькую карточку и ⋯, отмену «Увидел».
4. Заверши тестовую локальную задачу в Codex: сначала уведомление, затем открытие через выбранную задержку.
5. Проверь быстрые ответы сначала в режиме вставки. Затем при необходимости дай Accessibility и проверь автоотправку на тестовой задаче.
