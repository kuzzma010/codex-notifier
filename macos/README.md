# Codex Notifier для macOS

## Последние изменения

- Уведомление скрывается через 15 секунд; таймер автоматического открытия задачи продолжает работать независимо.
- Уменьшены отступы большой карточки, размер текста и кнопок сохранён.
- Иконка приложения включена в сборку. [Английская версия](../en/macos/README.md) доступна отдельно.

Для обновления закройте запущенную версию, выполните `bash Build.command` и замените прежнее приложение новым из `build`. Настройки сохраняются отдельно и остаются на месте. После замены проверьте разрешение Accessibility, если используете быстрые ответы.

Нативная версия для **macOS 13+**, Apple Silicon и Intel. `Build.command` собирает локально подписанный universal‑пакет и запускает встроенные проверки.

## Сборка с установленным Xcode

1. Распакуй архив на Mac.
2. Открой Terminal. Напиши `bash`, поставь пробел и перетащи файл **Build.command** в окно Terminal. Нажми Enter. Либо запусти Build.command двойным кликом, если Finder разрешает его запуск.
3. Сценарий соберёт обе архитектуры, создаст **build/Codex Notifier.app**, проверит локальную подпись и выполнит 22 проверки логики. При ошибке он остановится, не объявляя сборку успешной.
4. Перетащи полученный **Codex Notifier.app** в **Applications** и открой. При первом запуске появятся настройки.

Дополнительные пакеты, Homebrew и платные учётные записи для локальной сборки не нужны. Если `xcrun` не находит компилятор, открой Xcode → Settings → Locations → Command Line Tools и выбери установленный Xcode. Сценарий не меняет выбор Xcode и настройки безопасности самостоятельно.

## Что реализовано в исходниках

- Значок в строке меню: настройки, тест уведомления, переподключение, пауза, выход.
- Маленькая карточка: **Открыть** и **⋯**. Три точки разворачивают большую карточку без сброса отсчёта.
- Большая карточка: название задачи, отсчёт, открытие, «Увидел», быстрые ответы **Да / Дальше / Делай**.
- Системное стекло через NSVisualEffectView. Автоматическая тема macOS и ручной выбор светлой/тёмной.
- Звук, автоматическое открытие через 15/30/60 секунд, запуск при входе в систему.
- Быстрые ответы: вставлять для проверки (по умолчанию) либо отправлять сразу.
- Никакого отдельного AI/API-ключа: утилита взаимодействует с установленным Codex.

## Разрешения и быстрые ответы

Обычные уведомления не требуют управления клавиатурой. В текущей macOS‑версии Codex для надёжной вставки и режима «Отправлять сразу» требуется разрешить приложению **Универсальный доступ / Accessibility**. Кнопка запроса находится в настройках утилиты. Разрешение выдаётся пользователем в системных настройках; без него задача откроется, но ответ может потребовать ручной вставки. Запись экрана не используется.

Перед отправкой проверяются ID задачи, пустота существующего черновика, совпадение вставленного текста, активное приложение и доступное поле ввода. При ошибке отправка не повторяется автоматически. Доступность этих проверок зависит от версии Codex; автоотправку обязательно проверь на безобидной тестовой задаче. Никогда не используйте тестовое «Да» в задаче, где ожидается нежелательное для вас действие.

Ссылка `codex://threads/<id>` проверена в macOS‑версии Codex. Параметр `prompt` для существующей задачи эта версия игнорирует, поэтому Notifier безопасно находит только пустой активный ProseMirror‑редактор через Accessibility, вставляет текст и перечитывает его перед подтверждением или отправкой.

Автозапуск использует системный SMAppService. Если macOS требует одобрения, проверь System Settings → General → Login Items. Перемещать .app лучше до включения автозапуска. Для распространения другим людям потребуется отдельно подписать приложение Developer ID и пройти notarization; включённая ad-hoc подпись предназначена для локальной сборки.

## Нагрузка

Нативные AppKit/SwiftUI, без Electron и браузерного движка. Журналы отслеживаются через vnode‑события с резервным FSEvents; периодического обхода всех файлов нет. В покое нет таймера уведомлений. Отсчёт обновляется один раз в секунду и прекращается после закрытия карточки. Проверка быстрого ответа работает максимум 12 секунд после открытия Codex, только после нажатия кнопки. История дубликатов ограничена 2048 событиями, очередь уведомлений — 200 задачами, размер обрабатываемой строки — 1 МБ.

На тестовом Mac процесс занимал около **39 МБ RAM и 0% CPU в покое**; при открытии настроек и карточек — около **42–43 МБ**, с кратковременным пиком CPU около **17,7%**. Значения зависят от модели Mac и версии macOS.

## Локальные данные

- Читаемые журналы: `~/.codex/sessions/`.
- Названия: `~/.codex/session_index.jsonl`.
- Черновики: `~/.codex/.codex-global-state.json`, только для быстрых ответов.
- Настройки утилиты: `~/Library/Application Support/CodexNotifier/settings.json`.

Отслеживаются локальные задачи Codex. Облачные чаты и подтверждения посреди выполнения пока не поддерживаются. Смена полноэкранного режима не вызывается: приложение открывает задачу через системную ссылку.

## Проверка на Mac

1. Собери приложение: должны пройти компиляция обеих архитектур и все 22 core checks.
2. Запусти, выбери настройки и проверь сохранение после перезапуска.
3. Проверь светлую/тёмную тему, маленькую карточку и ⋯, отмену «Увидел».
4. Заверши тестовую локальную задачу в Codex: сначала уведомление, затем открытие через выбранную задержку.
5. Проверь быстрые ответы сначала в режиме вставки. Затем при необходимости дай Accessibility и проверь автоотправку на тестовой задаче.

## Обновление быстрых ответов

Автоотправка проверяет текст непосредственно через Accessibility, без ожидания сохранения черновика на диск. Движение мыши и отпускание кнопки не отменяют отправку. Новое нажатие клавиши, клик или прокрутка отменяют её; ввод повторно проверяется перед отправкой. Проверки выполняются только во время подготовки ответа, не более 12 секунд после открытия Codex. Всего 22 проверки логики запускаются при сборке на Mac.
